GOOGLE SHEETS LIVE ORDER SYNC
Automated Google Sheets Recording: Every order placed on XORONIQ is automatically pushed in real-time to your Google Spreadsheet via Google Apps Script.
Checking configuration...
How to set up your Google Sheet in 2 minutes:
  1. Create a new spreadsheet at sheets.new named "XORONIQ Orders".
  2. Click Extensions → Apps Script in the top menu.
  3. Copy & paste the script from google-apps-script.js (located in this website repo).
  4. Click Deploy → New deployment → Select Web app. Set "Who has access" to "Anyone" and click Deploy.
  5. Copy the Web App URL and paste it above!
